# 兼容性与验收

| MobSF 版本 | 检查结果 |
| --- | --- |
| 4.5.2 | 在原始镜像中生成 9 个模板。在运行实例访问 Android、iOS 历史网页和实际导出 PDF，检查风险正文、中文字体和表格布局。 |
| 4.5.4 | 模板结构检查通过。变更的文案来源列入兼容性报告，相应正文回退英文。 |
| 4.6.3 | 官方镜像的模板结构检查通过。未审校的新 Android 规则和已变更词组来源按预期回退。此版本仅验证了外挂生成检查。 |

验证涵盖以下行为。

- Android 和 iOS 历史网页及实际 PDF 的风险标题、正文和中文字体可显示。Windows 模板用样例验证内置风险文字，未对真实 Windows 扫描做验收。
- APK、源码 ZIP、IPA、APPX、PDF 和安全计分卡共 9 个模板通过 Django 编译。iOS ATS 与代码规则、Android API、权限说明和 Windows 的内置风险用公开规则或合成数据验证。
- 报告页面的侧栏、按钮、标题和表头由服务器直接输出中文。模板翻译保留数据和操作标识，包括风险抑制规则使用的原始 ID。
- 固定文本按原文匹配。动态参数继续经过模板转义，历史数据无需重新扫描。报告显示使用的样本数、风险级别、评分和 API 原始字段在验收中保持一致。
- 安装可重复执行。回滚恢复备份，并拒绝覆盖安装后被另行修改的文件。
- 扩展单元测试、词典一致性、Python lint 和 MobSF 的 `tox -e lint` 均通过。

## Android 计分卡补充验收

用 MobSF 4.5.2 的历史 Android 计分卡验证 554 条清单风险的标题和详情。清单风险和系统权限说明复用常规报告词典。保持原容器与镜像，原始清单结果、评分和历史记录均通过核对。另用已存在的 iOS 计分卡做回归。版本校验拒绝将声明为 4.6.3 的部署应用到这台 4.5.2 实例。

## Android 与 iOS 计分卡全量复核

对 MobSF 4.5.2 的 90 份 Android 和 39 份 iOS 历史计分卡逐项比较发现结果，共 12,752 个检查项。补齐 116 条 Android 网络安全和 191 条 iOS ATS 的标题、展开说明，并对照已安装的上游权限字典，补全此前缺失的 54 项 Android 高敏感权限文案。历史报告实际使用过其中 48 项 Android 高敏感权限和 13 项 iOS 内置权限。两平台全部 72 项 Android 高敏感权限、23 项 iOS 内置权限说明以及 97 种不同的内置代码风险文案分别按上游词条核对。历史样本没有代码命中行，代码详情的文件、行号标签用样例验证。

全量对照前后评分及各风险级数量的摘要一致。已登录复查 Android 网络安全、Android 清单和 iOS ATS 的实际页面响应，包括展开区正文与系统权限说明。目标实例继续使用原 4.5.2 镜像和同一容器。
